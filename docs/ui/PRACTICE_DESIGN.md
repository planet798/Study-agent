# Practice Workspace Design (UI-4)

> Project Portfolio / Evidence Workspace。回答“在做哪些项目、做到什么程度、
> 产出什么、还缺哪些能力？”不是 project dashboard。

## Overview（2026-10-04 精修）

- 状态筛选默认“全部未归档”，沿用未归档查询范围，不包含归档历史。
- 项目为轻量条目：名称 / 状态 / 查看项目 / 更多；类型与关联路线为次要信息，可换行。
- 四类指标独立：里程碑 x/y、成果数量、有效项目能力证据数量、学习准备度 x/y；禁止统一 project %。
- 编辑 / 归档 / 恢复进入菜单，沿用原服务与确认流程。
- 全库无项目 → 创建；当前状态无匹配 → 清除筛选；仅有归档项目 → 查看已归档；读取失败 → 重试。
- 四类指标读取失败独立显示“暂不可用”，未启用的模块显示“未启用”；不伪造零证据或零成果。
- 刷新与关闭详情保留概览滚动位置；切换筛选回到顶部。

## Detail（2026-10-04 · 保留弹窗）

初始 880×720 逻辑像素，受可用屏幕尺寸约束。正文采用轻量分区：

1. 顶部摘要：目标 / 状态 / 类型 / 四类独立指标。
2. 项目信息（默认折叠）：状态 / 类型 / 目标 / 描述。
3. 里程碑（默认展开）：完成状态、顺序；常用操作“开始”“标记完成”；
   “重置为待开始”、编辑、删除进入菜单，仍调用原状态转换与保护服务。
4. 项目成果（默认展开）：标题 / 类型 / 地址分行；地址支持鼠标选择和键盘复制，
   不自动打开网络或文件。编辑与删除进入菜单；保留新增入口。
5. 学习准备（默认折叠）：要求满足数 / 待补数 / 当前与目标能力 / 原因 / 下一步建议 /
   设置要求入口。“只展示、不驱动 Planner”状态仍可见。
6. 项目能力证据（默认折叠）：确认 / 查看 / 撤销入口、资格说明及历史状态。
7. 项目关联（默认折叠）：路线 / 技能 / 知识点，保留原管理入口。

同一次打开期间保留折叠选择、刷新滚动位置；手动滚轮、拖动、滚动按键与折叠会取消旧恢复。
内容减少时位置收敛到新最大值；关闭、accept/reject、延迟删除仍会使恢复失效。

## 业务边界

- 里程碑、成果、准备度、能力证据独立，不计算统一 project %。
- 项目完成不自动提升 Mastery；只有 active confirmed 项目使用证据支持 PROJECT / L5。
- 关联 Topic / Output / Milestone 都不暗示已有 L5。确认按钮依旧按原资格启用，
  原确认复选框、使用说明、支撑成果选择和撤销原因不省略。
- 成果曾被证据引用（含已撤销）后，原删除与关键字段修改保护继续生效；
  删除失败显示服务错误，不绕过保护或抛出未处理 Qt 异常。
- 数据读取失败显示“暂不可用”；没有服务时显示“未启用”，不伪造零计数。

## 工程职责

- `practice_page.py` 保留构造接口、导航、查询和服务操作编排。
- `practice_overview_widgets.py` / `practice_detail_sections.py` 展示快照，通过信号请求操作。
- 无业务依赖的菜单、折叠分区、位置恢复置于公共组件；路线仍保留原导入入口及样式标识。
- 新增 QSS 仅匹配实践页面控件，不改变已验收路线、对话、设置的外观。

## 验收场景

- 首次空态、筛选无结果、仅归档项目、读取失败与重试；默认筛选范围不变。
- 查看 / 编辑 / 归档 / 恢复菜单保留数据；筛选切换回顶部，刷新保持位置。
- 里程碑完整状态循环、成果编辑/复制/删除、证据资格与确认/撤销、历史保护。
- 折叠选择保持、键盘操作、旧恢复请求失效、内容缩短及关闭期间无跳位。
- 深浅主题、长名称、多路线、多成果；Windows 100%/125%/150%/175% DPI 需实机验收。

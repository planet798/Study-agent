Windows 10（1809 或更新版本）/11 x64 安装版，内置 Python、Qt、Node.js 与订阅登录组件。

本版更新：

- 对话默认 Enter 发送、Shift+Enter 换行；保留 Ctrl+Enter，中文输入法选词不误发送。
- 订阅请求复用按配置隔离的桥接进程与网络连接，收到结果立即交付；回答支持流式显示。
- 测试连接分别显示首字和完整请求耗时，保持原有模型与推理设置。
- 个人学习配置、交接、开发日志和历史审计记录不再随当前仓库公开，提供通用配置示例。

下载安装程序后双击安装，可自主选择目录；桌面和开始菜单快捷方式均可启动，无需终端命令。

从 0.2.0 升级：通过托盘菜单退出旧版，再运行新安装包。无需重新导入学习数据。
首次使用可全新开始，或选择旧版 data 目录导入。用户数据位于 `%LOCALAPPDATA%\StudyAgent\data`，覆盖安装与卸载保留数据。
数据库如需升级，程序先确认、备份并在副本上校验；备份位于 data/backups。

API Key 和订阅凭据继续保存在 Windows Credential Manager；跨电脑需重新配置或登录。
外部 MCP 服务与 Docker 按需自行配置。附件包含 SHA256 校验文件，首版安装程序未签名。

性能说明：流式首字、完整响应及离线桥接开销是不同指标。真实响应仍受服务端推理与网络影响，不承诺固定延迟。
